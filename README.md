# 文档 Diff

一个在本机运行的文档比对小工具。把旧版和新版放在左右两边，它会用红绿两色标出两边的不同之处。

所有处理都在你自己的电脑上完成，文件不会上传到任何地方。

## 打开方式

进入 `publish\aot` 文件夹，双击 `FileDiff.exe` 即可运行。这个文件夹里的文件要放在一起，不能只把 `FileDiff.exe` 单独拷走。

不需要另外安装任何运行环境。

## 两种用法

### 比较两个文件

1. 把旧版文件拖进左边的框，新版文件拖进右边的框（也可以点击框子，从本机选文件）。
2. 两边都放好之后自动开始比较。
3. 左侧的页面列表显示哪些页有差异；点一下就能跳到那一页看详情。

### 比较两个文件夹

1. 在上方切换到“文件夹比较”。
2. 左右各拖入一个文件夹。
3. 列表会逐层列出两个文件夹里的所有文件，并标出哪些相同、哪些有差异、哪些只在一侧存在。
4. 列表里两侧都有的文件，双击就能继续做逐字逐行的文本比较；按 `Esc` 或点“返回文件夹比较”回到列表。

## 能比较哪些文件

- PDF
- Word（`.docx`）
- RTF
- 各种纯文本：`.txt`、`.log`、`.csv`、`.md`，以及常见的代码、配置、脚本文件（如 `.cs`、`.json`、`.html`、`.sas`、`.sql`、`.py` 等）

## 界面上几个选项

| 选项 | 作用 |
| --- | --- |
| 同步滚动 | 左右两边一起上下滚动，方便对照 |
| 差异高亮 | 用红绿底色和斜线底纹标出有变化的地方 |
| all / diffs / same | 全部行 / 只看有差异的行 / 只看完全相同的行 |
| 忽略空白 | 空格、制表符的增减不算差异 |
| 全文模式 | 默认开启。把整篇文档当成一段文字连续比较，内容增删不会被页数变化放大成大量假差异 |

顶栏还有“上一差异 / 下一差异”用来逐处跳转，以及放大、缩小按钮（也可以用 `Ctrl` + 鼠标滚轮缩放）。

## 需要注意的地方

- 扫描件（图片型 PDF）里没有可读的文字，所以无法比较内容，也不做文字识别。
- PDF 的“全文模式”比较的是文字内容，不会还原表格边框和排版样式；如果更在意页面上的位置关系，可以取消勾选“全文模式”，改成按页面版式查看。
- 比较 PDF 的页数很多、文字很多时，第一次打开需要等几秒，期间可以点“取消”。
